# ✨ LuxeCart | Premium E-Commerce Experience

LuxeCart is a lightweight, responsive single-page web application designed to simulate a modern e-commerce storefront. Built using vanilla JavaScript, HTML5, and custom CSS, it features client-side state management and interactive features without requiring a full backend setup.

---

## 🚀 Features

* **Product Catalog:** Browse curated items with real-time dynamic pricing and descriptions.
* **Shopping Bag & Checkout:** Interactive cart management supporting item addition, quantity updates, removal, and order creation.
* **Role-Based Access (User / Admin):**
  * **User View:** Browse items, place orders, and view past order history.
  * **Admin Studio:** Add new products to the catalog, remove items, and view all global customer orders.
* **Persistent Data Simulation:** Uses browser `localStorage` and `sessionStorage` to maintain state across reloads.
* **Modern UI/UX:** Glassmorphic navigation bar, subtle CSS animations, and built-in toast notifications.
